京都府の地理：5エリアで把握する

更新日: 2026年5月17日

kyotogeography

京都府は南北に長く、エリアで景色が全く異なる。まずこの区分を頭に入れることが、あらゆる京都理解の出発点。

┌──────────────────┐
│  丹後（北部沿岸）  │ ← 日本海沿岸、リアス地形
├──────────────────┤
│  中丹（福知山周辺）│ ← 由良川流域、内陸盆地
├──────────────────┤
│  南丹（亀岡・美山）│ ← 丹波高地、霧の名所
├──────────────────┤
│  京都市域         │ ← 盆地、都市景観と山
├──────────────────┤
│  山城（宇治・南部）│ ← 宇治川流域、茶畑
└──────────────────┘

エリア概要

エリア 主な都市 地形の特徴 代表的な景観
丹後 宮津・京丹後 日本海沿岸・リアス 天橋立・伊根の舟屋・漁港
中丹 福知山・綾部・舞鶴 由良川流域・内陸盆地 由良川氾濫原・舞鶴港
南丹 亀岡・南丹市・京丹波 丹波高地・盆地 霧の亀岡・美山茅葺き集落
京都市域 京都市 三方を山に囲まれた盆地 碁盤目市街・東山寺社・嵐山竹林
山城 宇治・城陽・木津川 宇治川・木津川流域 茶畑・宇治川景観
